# Project Review: wiz (2026-09-19)

## Inconsistencies & Documentation Errors
1. **Dynamic Fallbacks for `any`/`unknown`**:
   - **Error**: `AGENTS.md` claims "Erlang, JSON, and validator codecs support `T = unknown` or `any` by emitting dynamic runtime best-effort encoders/decoders (`__wizEncodeErlangTextUnknown`, etc.)".
   - **Reality**: `src/generators/validator.ts` bypasses checks for `any`/`unknown` (simply returning `true`), and `src/generators/json.ts` relies on standard `JSON.stringify` serialization for complex untyped data. Neither emits a dedicated dynamic runtime encoder/decoder like Erlang does. This is a design/documentation mismatch.

2. **MCP Schema Validation**:
   - **Inconsistency**: The architecture invariants suggest "All spec generators" run `assertValidSpecDocumentSync` before emitting. While `openapi`, `asyncapi`, `openrpc`, and `schema` do, `src/generators/mcp.ts` lacks validation entirely. There is no `mcp.json` meta-schema in `schemas/`.

## Testing Gaps
The following logic is unexercised by the test suite (`bun test`):
1. **TypeScript Extractor (`src/extractors/typescript.ts`)**:
   - `unknown`, `any`, and `symbol` AST parsing branches are uncovered (lines 347-363).
2. **JSON Schema Extractor (`src/extractors/jsonSchema.ts`)**:
   - Array parsing logic for nested `oneOf` and `anyOf` arrays is ignored by tests (lines 142-156).
   - Enum extraction paths—especially for single-value enums and mixed-type union fallbacks—are entirely untested (lines 63-79).
3. **Java Generator (`src/generators/java.ts`)**:
   - `toJavaType` misses test coverage for the vast majority of primitive mappings (`unknown`, `any`, `boolean`, `number`, `date`, `null`, `void`).
   - The `mimetypeToSuffix` utility function is completely uncovered.
4. **CLI Argument Parsing (`src/cli/generate.ts`)**:
   - Error throwing for invalid `--format` inputs, as well as handling for the `--media-types` array expansion and `--lenient` flags, lack coverage (lines 118-149).
5. **Unused Test Fixture Branch (`test/fixtures/readmeFixture.ts`)**:
   - The `nameOf(value: unknown)` function is never invoked at runtime, meaning its internal type guard `if (is<User>(value))` goes untested functionally.
