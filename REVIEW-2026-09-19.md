1. **~~Dynamic Fallbacks for `any`/`unknown`~~ (Resolved)**:
   - **Correction**: `AGENTS.md` previously claimed JSON and Validator codecs emit dynamic runtime best-effort encoders, which conflicted with the implemented use of native JS mechanics (`JSON.stringify` and returning `true`). The invariant has been corrected to clarify that only non-JS targets (like Erlang/CBOR) emit custom dynamic encoders.

2. **~~MCP Schema Validation~~ (Resolved)**:
   - **Correction**: The initial review flagged `mcp.ts` for lacking `assertValidSpecDocumentSync`. This was a misinterpretation; `AGENTS.md` explicitly lists only the JSON schema-backed generators that require validation. The invariant in `AGENTS.md` has now been updated to explicitly state that formats lacking formal JSON meta-schemas (like MCP and Protobuf) are exempt.
